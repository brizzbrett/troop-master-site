---
title: "0.1.4: The evidence, and four bosses you have to find"
date: 2026-08-01
summary: Troop 13's paperwork doubled, and finishing a case file now changes the game.
---
**The evidence collection roughly doubled.** Troop 13's paperwork is now sorted into more case files, and four of them belong to a single map each. Their notes only turn up there, so finishing the collection means playing all four maps.

**Finishing a case file can change the game.** A banner tells you when it has.

**Four new bosses, one per map.** They aren't in the regular rotation. You unlock each one by completing that map's case file, and it shows up on the next boss night. You'll have to find them yourself.

**The morning camp sign gives a hint.** On a boss day it tells you which animal is coming that night. The boss is chosen at dawn and saved with the run, so the hint is always right and reloading won't change it.

**The traveling trader has a name:** the Hooded Haggler.

This build went to the playtesters.
